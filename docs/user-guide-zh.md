## 1. 简介

TagScope 是一个网页版的 UHF RFID 读写器测试与标签观测工具，界面结构和操作流程参照 Impinj ItemTest 2.14.1。主要用途：

- 同时连接多台读写器做盘点，查看每个标签的读取次数、RSSI、天线、相位角、多普勒频率等数据。
- 用余量测试（逐级提高功率）评估标签的读取余量。
- 用 Gen2 Select 过滤、Session、搜索模式、Fast ID、低占空比等参数调试读取效果。
- 读写标签存储区，修改 EPC，设置访问密码，锁定或灭活标签。
- 用 GPI 触发盘点，手动控制 GPO 输出。
- 载入“关注标签”清单，在盘点结果中按颜色标出指定标签，并统计漏读。

支持三类数据源：

| 接口 | 适用设备 | 能力 |
|---|---|---|
| Impinj LLRP 接口 | Speedway R120 / R220 / R420、xPortal、xArray / xSpan（盘点），以及切换到 LLRP 模式的 R700 / R660 | 功能最完整：盘点、过滤、GPI/GPO、标签读写、锁定、灭活、低占空比 |
| Impinj IoT 设备接口（R700 REST） | 运行 IoT Device Interface 的 R700 / R660 | 盘点、Gen2 过滤、相位角；不支持标签读写和 GPI 触发 |
| 模拟读写器 | 不需要硬件 | 模拟一批常见芯片的标签，支持全部功能，用于熟悉界面和演示 |

> TagScope 是独立项目，与 Impinj, Inc. 无关联。Impinj、ItemTest、Octane、FastID、TagFocus 是 Impinj, Inc. 的商标。

## 2. 安装与运行

### 2.1 两种使用方式

| 方式 | 打开地址 | 何时使用 |
|---|---|---|
| 在线网页版 | <https://tagscope.iotrfid.top> | 推荐。只用模拟器时无需安装任何东西；连接真实读写器时需要在本机运行桥接服务 |
| 本机版 | <http://localhost:8080> | 运行桥接服务后直接打开，界面与在线版相同，不涉及跨域和浏览器网络权限 |

### 2.2 为什么需要桥接服务

浏览器不能直接建立 TCP 连接，无法访问读写器的 LLRP 端口（5084）。R700 的 REST 接口默认使用自签名 HTTPS 证书，一般也不允许网页跨域访问。因此连接真实读写器时，需要在**能访问读写器的电脑**上运行 TagScope 桥接服务 `server.js`：

```
浏览器 ⇄ HTTP / SSE ⇄ server.js（桥接服务）⇄ LLRP TCP 5084 或 HTTPS REST ⇄ 读写器
```

标签数据只在浏览器和本机桥接服务之间传输，不经过 Cloudflare 或其他服务器。

### 2.3 安装桥接服务

1. 安装 Node.js 18 或更高版本（<https://nodejs.org>）。
2. 从 GitHub 下载源代码（Code → Download ZIP）并解压。项目不依赖任何 npm 包，无需 `npm install`。
3. 启动：
   - Windows：双击 `start-windows.bat`
   - macOS / Linux：运行 `./start.sh`，或在项目目录执行 `node server.js`
4. 控制台显示监听地址后，打开 <http://localhost:8080>，或在在线版中把“桥接服务地址”设为 `http://localhost:8080`。

> 2.0 版网页需要 2.0 及以上的桥接服务（多数据源接口）。如果“更新”页显示的桥接服务版本低于 2.0，请重新下载。

### 2.4 桥接服务参数

```
node server.js --port=8080 --host=127.0.0.1 --verbose --allow-origin=https://example.com
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--port` | 8080 | 监听端口，也可用环境变量 `PORT` |
| `--host` | 127.0.0.1 | 监听地址。设为 `0.0.0.0` 允许局域网中其他电脑访问（注意安全） |
| `--verbose` | 关闭 | 在控制台打印 LLRP 协议细节，便于排查问题 |
| `--allow-origin` | — | 允许其他网页来源调用桥接服务，多个用逗号分隔；也可用环境变量 `TAGSCOPE_ALLOW_ORIGIN` |

桥接服务默认只接受本机页面和 <https://tagscope.iotrfid.top> 的请求。

### 2.5 浏览器要求

- 推荐 Chrome、Edge 或 Firefox 的最新版本。
- 在线版第一次访问本机桥接服务时，Chrome / Edge 会询问“是否允许该网站访问本地网络 / 本设备上的应用”，请选择**允许**。如果误点了拒绝，可在地址栏左侧的网站设置中重新允许。
- Safari 会阻止 https 页面访问 http 本机服务。使用 Safari 时请直接打开 <http://localhost:8080>。
- 数据源、预设、关注标签、显示设置等都保存在浏览器本地存储中。换浏览器或清除网站数据后需要重新配置；预设可以导出为 JSON 备份。

| 分组 | 项目 | 说明 |

| | 定位、方向 | 需要 xArray / xSpan 网关，当前版本只保留入口 |

## 4. 数据源

数据源即 TagScope 获取标签数据的读写器或网关。

### 4.1 添加数据源

点击左侧“数据源”旁的 ⊕，填写：

| 字段 | 说明 |
|---|---|
| 主机名 | 读写器 IP 或主机名，例如 `192.168.1.242`、`impinj-12-34-56.local`。LLRP 可写成 `主机:端口` |
| 昵称（可选） | 在界面中显示的名称，必须唯一 |
| 数据源接口 | Impinj LLRP 接口 / Impinj IoT 设备接口（R700 REST）/ 模拟读写器 |
| 模拟标签数量 | 仅模拟器：场内模拟标签数量 |
| 桥接服务地址 | 仅在线版、真实读写器：默认 `http://localhost:8080`；桥接服务运行在其他电脑上时填写其地址 |

**高级选项**

| 字段 | 说明 |
|---|---|
| 端口 | 留空使用默认端口：LLRP 5084；REST 为 443（TLS）或 80 |
| 认证方式 | REST：Basic |
| 使用 TLS / 允许自签名证书 | REST：R700 默认使用 HTTPS 和自签名证书，一般两项都勾选 |
| 覆盖默认凭据 | REST：默认账号 root / impinj；修改过密码时勾选并填写 |

点击“添加数据源”后，新数据源会出现在左侧列表，并自动启用和连接。

### 4.2 数据源列表

- **开关**：打开时连接读写器并参与盘点；关闭时断开连接。
- **名称**：点击进入该数据源的配置页（见第 5 章）。
- **悬停**：显示主机名、接口、型号、区域等信息。
- **状态**：连接失败或读写器不可达时显示错误，可点击“重试”。
- **右键菜单**：编辑数据源、设备信息、连接 / 断开连接、删除数据源。

> 一台读写器同一时间只接受一个 LLRP 客户端。连接前请关闭 ItemTest、MultiReader 等其他软件。TagScope 连接时会把读写器 LLRP 配置恢复为默认值（与 ItemTest 一致）。

## 5. 数据源配置与预设

点击数据源名称打开配置页，分为“盘点”和“诊断”两个标签页。

### 5.1 预设

预设是一组盘点参数，每个数据源可以有多个预设，当前使用的预设在下拉框中标为“（当前）”。

- **default**：根据读写器能力自动生成，只读。修改 default 后点击“保存”，会提示另存为新预设（默认名 `copy_of_default`）。
- **刷新能力**：重新读取读写器能力（天线数、RF 模式、功率表等）并更新 default。
- **导入 / 导出**：以 JSON 文件备份或分享预设。
- **复制**：以当前设置复制出一个新预设。
- **重置**：放弃未保存的修改，恢复为上次保存的值。
- **删除**：删除当前预设（default 不能删除）。

修改参数后必须点击“保存”才会生效；离开页面前若有未保存修改，会提示确认。

### 5.2 手动设置

| 参数 | 说明 |
|---|---|
| 天线 | 参与盘点的天线编号，逗号分隔，如 `1, 2, 3, 4`；“全部”选中所有天线，“清除”清空 |
| RF 模式 | 列表来自读写器能力表，例如 Impinj 的 AutoSet 1002、Max Throughput、Dense Reader M4/M8 等 |
| 搜索模式 | Single Target / Dual Target / TagFocus™（Single Target w/ Suppression）/ Single Target Reset / Dual Target Select B to A |
| 启用 Fast ID | 在 EPC 回复中同时返回 TID，用于识别标签型号（需 Impinj 芯片支持） |
| 预估标签数量 | 读写器据此选择初始 Q 值 |
| Session | Session 0–3 |
| 报告相位角 / 报告多普勒频率 | 在标签报告中包含相应数据 |

**常用组合**

- 统计场内全部标签数量：Single Target + Session 2 或 3，每个标签每轮只回复一次。
- 持续观察信号变化（RSSI、相位）：Dual Target + Session 0 或 1。
- 每次运行前把标签恢复为 A 状态：使用 Single Target Reset，或在盘点展示设置中开启“将标签重置为 A 状态”（见 7.3）。

### 5.3 功率与灵敏度设置

- **功率 (dBm)**：所有天线的发射功率，可选值来自读写器功率表。
- **接收灵敏度 (dBm)**：可选值来自读写器灵敏度表。
- **启用最大灵敏度**：勾选后使用读写器最大灵敏度（显示为 −80 dBm），接收灵敏度下拉框变灰。
- **单独设置天线**：展开后可为每个天线分别设置功率和灵敏度，未设置的天线使用上面的全局值。

### 5.4 GPI 配置

表格列出读写器的每个 GPI 端口，可勾选“启动”和“停止”并选择触发电平（高 / 低）。

- 只在盘点展示的“GPI 触发”运行场景中生效（见 7.2）。
- 同一端口同时作为启动和停止时，两者电平不能相同，否则该行标红且不能保存。
- IoT 接口（REST）暂不支持 GPI 触发。

### 5.5 Gen2 过滤

最多 5 个 Gen2 Select 过滤器，按顺序执行。每个过滤器包含：

| 字段 | 说明 |
|---|---|
| 存储区 | EPC / TID / USER |
| 偏移（位） | 掩码起始位置。EPC 区中 EPC 编码从第 32 位开始（前面是 CRC 与 PC） |
| 掩码（十六进制） | 要匹配的数据 |
| 位长度 | 掩码的有效位数，留空按掩码长度计算 |
| 匹配动作 / 不匹配动作 | 选择 (Select) / 无动作 (Do Nothing) / 取消选择 (Unselect)，两者不能相同 |

多个过滤器的动作组合可实现“与 / 或 / 非”逻辑。例如：

- 只读 EPC 以 `E280` 开头的标签：存储区 EPC，偏移 32，掩码 `E280`，匹配 = 选择，不匹配 = 取消选择。
- 排除某一类标签：匹配 = 取消选择，不匹配 = 选择。

### 5.6 低占空比（Low Duty Cycle）

需要 Impinj 扩展（Octane LLRP）。启用后，天线在一段时间内（空场超时）读不到标签就进入低占空比状态，按“场探测间隔”周期性探测，有标签进入时恢复正常盘点，以降低功耗和干扰。

| 参数 | 默认值 |
|---|---|
| 空场超时 (ms) | 500 |
| 场探测间隔 (ms) | 200 |

### 5.7 诊断

- **GPO 控制**：直接切换读写器每个 GPO 输出的高 / 低电平，用于测试指示灯、蜂鸣器、闸机等外设。
- **模拟 GPI 输入（仅模拟器）**：手动改变模拟读写器的 GPI 电平，用于演练 GPI 触发。
- **设备信息**：制造商、型号、序列号、固件版本、区域、天线端口（未接天线的端口带叉号标记）、发射功率范围、RF 模式数、GPI / GPO 数量、频道数，以及连接状态。

## 6. 盘点展示

### 6.1 开始与停止

- 顶部 ▶ 开始盘点，■ 停止。所有**已启用且已连接**的数据源会同时按各自当前预设开始盘点。
- 秒表显示本次运行的读取时长。
- 齿轮按钮打开“盘点展示设置”（第 7 章）。
- 页脚显示当前运行场景与进度（如“第 2/5 次”“等待 GPI 启动信号”）、唯一标签数和读取速率（次/秒）。

### 6.2 列表视图

每个唯一 EPC 占一行。可显示的列：

| 列 | 说明 |
|---|---|
| # | 首次读到的顺序 |
| EPC / TID | 标签 EPC 和 TID（TID 需启用 Fast ID 或读过 TID） |
| XPC Words | 扩展 PC 字 |
| 读取次数 | 本次运行累计读取次数 |
| 最后读取自 | 最后一次读到该标签的数据源 |
| 首次读取 / 最后读取 | 相对本次运行开始的时间 |
| 距上次读取 | 距最后一次读到的时长 |
| 读写器最后读取时间 | 读写器报告的时间戳 |
| 标签型号信息 | 根据 TID 解析，如 `CLASS E2 : IMPINJ : M730` |
| 最近 RSSI / RSSI 平均 / 最大 / 最小 | 单位 dBm |
| 天线 | 最后读到的天线编号 |
| 功率 | 余量测试中首次读到该标签时的功率 |
| 相位角 / 多普勒频率 / 频率 (MHz) | 需在预设中启用相应报告 |
| PC 字 / CR Handle Hex | 协议控制字与 RN16 Handle |

**操作**

- **选择列**：右键任一列标题，勾选或取消勾选列。
- **调整列顺序**：拖动列标题。
- **排序**：点击列标题，再次点击切换升序 / 降序。
- **行变灰**：标签超过 1 秒未被读到时，行背景开始变灰，约 15 秒后变为最深的灰色，便于发现离场标签。
- **关注标签**：属于已启用关注标签文件的标签，EPC 单元格按文件中的颜色着色。

**标签右键菜单**

- **标签存储访问**：打开标签存储页并选中该标签。
- **修改 EPC**：写入新 EPC。新 EPC 必须是整字（4 位十六进制的倍数），最长 496 位；长度变化时 TagScope 会同时更新 PC 字中的 EPC 长度。需要 LLRP 接口或模拟器。
- **复制 EPC / 复制 TID**。
- **EPC / TID / 其他列**：在十六进制和 Base64 显示格式之间切换。

### 6.3 表格视图

按“数据源 × 关注标签文件”统计已读标签数。不属于任何关注标签文件的标签计入“Strays（游离）”。可在设置中勾选“行列互换”。

“显示关注标签汇总”打开且有已启用的关注标签文件时，盘点页底部显示汇总：已读关注标签数 / 关注标签总数、百分比，以及本次读到的唯一标签总数。

### 6.4 唯一标签曲线

在设置中勾选“显示唯一标签曲线”后，盘点页显示唯一标签数随时间变化的曲线，用于观察读取收敛速度。

## 7. 盘点展示设置与运行场景

点击盘点页的齿轮按钮打开。修改后点击“保存”。

### 7.1 盘点显示

- 列表视图 / 表格视图
- 行列互换（表格视图）
- 显示关注标签汇总

### 7.2 运行场景

**连续 - 永久运行**：点击开始后一直盘点，直到点击停止。

**定时 - 按指定时间间隔运行**

| 参数 | 说明 |
|---|---|
| 启动延迟 (s) | 点击开始后等待多久再开始第一次运行 |
| 开启时间 (s) | 每次运行的盘点时长 |
| 关闭时间 (s) | 两次运行之间的间隔 |
| 启动时蜂鸣 | 每次运行开始时发出提示音 |
| 运行次数 | 总运行次数 |

**余量测试 - 逐级提高功率的连续多次运行**

| 参数 | 说明 |
|---|---|
| 起始功率 (dBm) | 第一次运行的功率 |
| 结束功率 (dBm) | 最后一次运行的功率，不能小于起始功率 |
| 功率步进 (dBm) | 每次运行增加的功率，运行次数自动计算 |

余量测试同样使用上面的启动延迟、开启时间、关闭时间和蜂鸣设置。列表中的“功率”列记录每个标签**首次被读到时的功率**，即该标签的读取门限，可用来比较不同标签或不同位置的读取余量。

> 使用 Session 2 / 3 时，标签读过一次后会保持 B 状态，下一功率级可能读不到。建议同时开启“将标签重置为 A 状态 → 每次运行前”（见 7.3），或使用 Session 0。

**GPI 触发 - 由 GPI 启动（及可选停止）**

- 只能启用一个数据源，且该数据源当前预设中必须勾选了 GPI 启动端口（见 5.4）。
- 点击开始后进入“等待 GPI 启动信号”状态；GPI 满足启动条件时开始读取。配置了停止端口时，满足停止条件即停止读取并回到等待状态；未配置时持续读取，直到点击 ■。
- “GPI 启动时总是重置秒表”：每次 GPI 启动时秒表从 0 开始。
- 使用模拟器时，可在数据源配置页“诊断 → 模拟 GPI 输入”中手动切换 GPI 电平来演练。

### 7.3 附加功能

| 选项 | 说明 |
|---|---|
| 显示唯一标签曲线 | 见 6.4 |
| 启用手动十六进制 / Base64 格式 | 盘点运行中默认按十六进制显示；勾选后，标签右键菜单中设置的十六进制 / Base64 格式在运行中也立即生效 |
| 将标签重置为 A 状态 | 在“首次运行前”或“每次运行前”用 Single Target Reset 把场内标签恢复为 A 状态；“重置时长”为重置操作持续的秒数。适用于 Session 2/3 下的重复测试 |
| 读取速率窗口 (s) | 计算读取速率的滑动窗口；0 表示按整个运行时长计算（不含启动延迟与关闭时间） |

## 8. 关注标签

关注标签（Tags of Interest）是一组需要重点观察的 EPC。载入后，这些标签在列表中按颜色标出，并可在表格视图中统计已读与漏读。

### 8.1 文件格式

**JSON（ItemTest 格式）**

```json
{
  "Name": "货架A",
  "Version": "1.0.0",
  "Tags": [
    { "Epc": "E2801190200000000000A001", "Color": "#FF8800" },
    { "Epc": "E2801190200000000000A002", "Color": "LightGreen" }
  ]
}
```

**CSV（旧版格式）**：每行一个 EPC，可选 `Color=<颜色>`；以 `#` 开头的行和 `EPC` 表头行会被忽略。

```
EPC,Color
E2801190200000000000A001,Color=Orange
E2801190200000000000A002
```

颜色可以是 CSS 颜色名或 `#RRGGBB`；未指定颜色时使用文件的默认颜色。

### 8.2 载入与管理

- 点击“关注标签”旁的 ⊕ 选择一个或多个文件。
- 每个文件前的开关控制是否启用；徽标显示已启用文件中的标签总数。
- 不能载入与已有文件同名的文件。
- 与已启用文件存在重复 EPC 的文件可以载入，但不会自动启用。
- 无效 EPC 行会被跳过，并提示跳过的行数。
- 点击文件名查看明细：每个 EPC 的颜色、本次是否读到、读取次数；可“导出 JSON”或“移除此文件”。

## 9. 标签存储

用于读写单个标签的存储区，对应 ItemTest 的 Tag Memory 展示。需要 LLRP 接口或模拟器。

### 9.1 选择标签

- 在盘点列表中右键标签 → “标签存储访问”，或在左侧点击“标签存储”后手动填写。
- **数据源**：执行操作的读写器。
- **TID / EPC**：单选决定按哪一项选中目标标签。按 TID 选中更可靠（多个标签可能有相同 EPC，TID 通常唯一）；按 TID 选中时需要先读到 TID（启用 Fast ID）。
- 顶部显示根据 TID 识别出的标签型号；未知时提示“启用 FAST ID 以识别”。

### 9.2 读取与写入

| 参数 | 说明 |
|---|---|
| 存储区 | RESERVED（灭活 / 访问密码）、EPC、TID、USER |
| 字数 | 1–32 个字（每字 16 位） |
| 字偏移 | 起始字地址。EPC 区中第 0 字为 CRC，第 1 字为 PC，EPC 从第 2 字开始 |
| 访问密码 | 标签已设置访问密码时填写，8 位十六进制 |

- **读取**：读取结果填入 32 个字框，同时以 ASCII 显示。
- **写入**：把字框中的数据写入标签。可直接编辑十六进制字框，也可编辑 ASCII，两者双向同步。
- **使用块写（BlockWrite）**：一次写入多个字，速度更快；部分芯片不支持。
- **复制到剪贴板**：复制当前字框中的数据。
- 状态栏显示“就绪 / 读取成功 / 写入成功 / 错误原因”，右上角秒表显示操作耗时。操作超时为 5 秒。

### 9.3 设置访问密码

点击“设置访问密码”，向 RESERVED 区第 2–3 字写入新的访问密码。设置后，锁定的存储区需要提供访问密码才能写入。

### 9.4 锁定与灭活（TagScope 扩展）

ItemTest 没有提供此功能，TagScope 作为扩展加入。

- **锁定**：选择锁定区域（EPC / USER / TID / 访问密码 / 灭活密码）和锁定权限（锁定 / 解锁 / 永久锁定 / 永久解锁），点击“执行锁定”。访问密码为 0 时，任何人都能解锁，因此锁定前通常先设置非 0 的访问密码，并在“访问密码”框中填写。
- **灭活**：填写非 0 的 8 位十六进制灭活密码（需事先写入标签 RESERVED 区第 0–1 字），点击“灭活标签”。

> ⚠️ 永久锁定和灭活都**无法撤销**。界面会先要求确认，请务必确认目标标签。

## 10. 标签日志

在左侧“设置 → 标签日志”中配置。

- **记录标签数据**：启用后，每次盘点运行结束（定时、余量测试的每一次运行都算一次）自动下载一个 CSV 文件到浏览器默认下载目录。
- **文件名前缀**：默认 `TagScope`，文件名格式为 `前缀_时间戳.csv`；多次运行的场景会在文件名后附加运行序号。
- **生成唯一标签日志**：同时下载一份唯一标签列表（列与当前列表视图一致）。
- **下载当前读取日志 / 下载唯一标签列表**：随时手动下载当前缓存的数据。

读取日志 CSV 以 `#` 开头的若干行文件头记录运行时间、运行场景和每台读写器的主机名、接口、型号、固件、预设、天线、RF 模式、Session、搜索模式、功率、Fast ID 等信息，随后是数据行：

```
Timestamp,EPC,TID,Antenna,RSSI,Frequency,Hostname,PhaseAngle,DopplerFrequency,Power,ReadCount
```

## 12. 常见问题

**在线版提示无法连接桥接服务**

1. 确认本机已运行 `node server.js`，并能打开 <http://localhost:8080>。
2. 确认“桥接服务地址”填写正确（默认 `http://localhost:8080`）。
3. Chrome / Edge 中确认已允许本网站访问本地网络（地址栏左侧 → 网站设置）。
4. Safari 不支持此方式，请改用本机版 <http://localhost:8080>。
5. 如果桥接服务运行在其他电脑上，启动时加 `--host=0.0.0.0`，并确认防火墙已放行端口。

**LLRP 连接失败或很快断开**

- 读写器同一时间只接受一个 LLRP 客户端，请关闭 ItemTest、MultiReader、读写器上的其他应用。
- 确认电脑能 ping 通读写器，且 5084 端口未被防火墙拦截。
- R700 / R660 需要在读写器网页中切换到 LLRP 模式才能用 LLRP 接口；否则请选择 IoT 设备接口。
- 启动桥接服务时加 `--verbose` 查看协议细节。

**R700 REST 连接失败**

- 确认 IoT Device Interface 已启用，并勾选“使用 TLS”和“允许自签名证书”。
- 修改过默认密码时，在高级选项中勾选“覆盖默认凭据”并填写账号密码。

**读到的标签数比预期少**

- 检查天线是否全部选中、功率是否过低、Gen2 过滤是否把标签排除在外。
- Session 2 / 3 + Single Target 下，标签读过一次后会保持 B 状态一段时间，重复测试前请开启“将标签重置为 A 状态”。
- 用余量测试找出各标签的读取门限。

**标签存储读写失败**

- 确认使用 LLRP 接口或模拟器（REST 接口不支持标签读写）。
- 写入锁定区域需要正确的访问密码。
- 标签距离天线太远时写入容易失败，写入所需功率通常高于读取。
- 部分芯片不支持 BlockWrite，失败时取消勾选“使用块写”再试。

**数据源和预设丢失**

所有配置保存在浏览器本地存储中，按网站地址区分：在线版和本机版的配置互不共享。清除浏览器数据或更换浏览器后需要重新配置。请定期导出重要预设。

### 13.2 与 ItemTest 2.14.1 的差异
